# سكرابر الأطلس

أداة جمع وتحقق مجمّع من مصادر مفتوحة، مصممة لتكون **سريعة** (طلبات مجمّعة، لا طلب لكل عنصر) و**مهذّبة** مع الخوادم و**شفافة** في أحكامها.

## المبادئ
- **لا تطبيق آلي**: الأداة تقترح وتقيّم وتكتب ملف مراجعة. القرار لصاحب المشروع، والتطبيق خطوة منفصلة.
- **طلبات مجمّعة**: ويكيبيديا 50 عنواناً في الطلب، وSPARQL ويكي بيانات حتى 120 معرّفاً في الاستعلام.
- **احترام الخوادم**: حد أدنى للفاصل بين الطلبات لكل مضيف (`core.MIN_INTERVAL`)، واحترام `Retry-After`، وتراجع أسّي. إن طلب الخادم انتظاراً أطول من دقيقتين، تؤجَّل الخطوة ولا تتوقف المهمة.
- **ذاكرة مؤقتة على القرص** في `.cache/scraper/` (مستثناة من Git): إعادة التشغيل لا تعيد الطلبات الناجحة لمدة 30 يوماً.
- **الهوية**: ترويسة `User-Agent` برابط المستودع، لا ببريد شخصي.

## المصادر (المحولات)
| المصدر | الاستعمال | الحد |
|---|---|---|
| ويكيبيديا الإنجليزية (`en.wikipedia.org`) | عنوان ← معرّف ويكي بيانات، والتحويلات، وصفحات التوضيح، والعنوان العربي من روابط اللغات | سريع، غير مقيّد عادة |
| بحث ويكيبيديا النصي | اقتراحات لما لا مقالة له بعنوانه | اقتراحات فقط، للمراجعة |
| SPARQL ويكي بيانات (`query.wikidata.org`) | الأنواع (P31) والنشأة والزوال والاسم العربي، والمطابقة بالاسم | يُحجب أحياناً بالسرعة؛ تُؤجَّل خطوته |

## المهام
### `verify-names`: التحقق الجماعي من الأسماء العربية
```bash
python3 -I scripts/scraper/run.py verify-names            # كل الأسماء غير الموثّقة (معرَّبة، بلا تطابق، بلا تاريخ)
python3 -I scripts/scraper/run.py verify-names --limit 100
```
يكتب `review/names_verification.csv` (للفتح في جدول) و`.json`. لكل اسم: المعرّف المرشح، والاسم العربي المقترح (عنوان المقالة العربية أولاً)، والتاريخ والأنواع إن توفرت، والدرجة، والمستوى، والأسباب، وعمود `accept` يملؤه صاحب المشروع.

**قواعد التقييم** (`verify_names.score`):
- مقالة بالعنوان نفسه +3، وتحويل إلى مقالة +2، ومطابقة الاسم في ويكي بيانات +1، واقتراح البحث النصي +0.
- نوع سياسي +2، وشعب أو ثقافة +1، ونوع آخر −3، وصفحة توضيح −10.
- تاريخ يغطي كل سنوات الخريطة (بتسامح 50 سنة) +2، وخارجها كلها −3.
- اسم عربي متاح +1.
- **عالية**: 6 فأكثر، مع تطابق تام للعنوان (لا تحويل)، واسم عربي، ونوع وتاريخ معروفان، وبلا تعارض. التحويل لا يكفي، لأنه قد يربط كياناً مختلفاً (مثل Saka Kingdom ← الإصقوثيون).
- **متوسطة**: 3 فأكثر، بمطابقة عنوان أو تحويل. **منخفضة**: ما دون ذلك، ومنها كل اقتراحات البحث النصي.

**روابط التحقق**: كل صف فيه `url_en` و`url_ar` و`url_wikidata`، فيفتح القارئ المصدر بنفسه قبل القبول.
**التعارض**: إن كان الاسم الموثّق حالياً يختلف عن المقترح، يُكتب في عمود `conflict`.
**التكرار**: إن اقترح معرّف واحد لأكثر من اسم، يُكتب الأسماء الأخرى في `duplicate_of`، فيُتخذ قرار واحد.

### مساران للبيانات
- **SPARQL** (`query.wikidata.org`): الأسرع حين يتاح، ويجلب الأنواع والتواريخ دفعة واحدة.
- **بيانات الكيان** (`Special:EntityData`): البديل حين يُحجب SPARQL. أبطأ قليلاً، لكنه يعمل، والنتائج تُحفظ في الذاكرة المؤقتة.
- يُختار مرشح واحد لكل اسم (الأقوى)، فيتناسب عدد الطلبات مع عدد الأسماء.

### أدوات بحث عامة
```bash
python3 -I scripts/scraper/run.py wiki-qids "Ming dynasty" "Song Empire"   # عناوين ← معرّفات وأسماء عربية
python3 -I scripts/scraper/run.py sparql query.rq                          # استعلام SPARQL حر
```

## إضافة مهمة جديدة
مهمة جديدة ملف في `scripts/scraper/` فيه `run(wm, ...)`، تستعمل المحولات في `wikimedia.py` أو محولاً جديداً يستعمل `core.fetch`، ثم أمر في `run.py`.
