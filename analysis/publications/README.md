# أوراق التقدير (داخلية)

مولَّدة بـ `node scripts/build_publications.mjs` من `analysis/publications/papers.json`. لا تُنشر قبل بوابة التراخيص وقرار صاحب المشروع.

| الورقة | السؤال | السنن |
|---|---|---|
| [الدولة والسوق](pub_state_market.md) | متى يعمّر الأمن الأسواق، ومتى تفسدها الدولة بالجباية والتجارة؟ | سُنّة الأمن على الأموال وعمران الأسواق، سُنّة التجارة ومراكزها، سُنّة الجباية: قلة الوزائع وكثرة الجملة، سُنّة تجارة السلطان، سُنّة الدولة السوق الأعظم |
| [الصدمات والعمران](pub_shocks.md) | كيف تُضعف الأوبئة والمجاعات والحصار قوة الدولة، وما حدود هذا الضعف؟ | سُنّة الوباء والموتان، سُنّة المجاعة وترك الفلح، سُنّة العمران البشري وقوة الدولة، سُنّة الإمداد والحصار |
| [الغلبة والتماسك وأعمار الدول](pub_cohesion.md) | ما الذي يحمل الجماعة إلى الغلبة، وما الذي يُهرم الدولة بعدها؟ | سُنّة العصبية والملك، سُنّة أعمار الدول، سُنّة الترف والهرم، سُنّة المماليك والدولة |
| [الثقافة والمعرفة تحت الغلبة](pub_culture.md) | هل يقلّد المغلوب الغالب في لغته وعوائده وصنائعه؟ | سُنّة اقتداء المغلوب بالغالب، سُنّة لغة الأمصار، سُنّة الصنائع وانتقال المعرفة |
