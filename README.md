# الأطلس الشامل

أطلس تفاعلي يجمع التاريخ والجغرافيا والثقافة والسكان على خريطة، ويبني "السنن" من شواهد موثّقة الأصل. (الاسم السابق: أطلس السُّنن.)

## المرحلة 0: الأساس التقني

خطة التشغيل الكاملة: https://claude.ai/code/artifact/d7a48e2d-c988-4748-a9a7-890a81bacb0b

## ما هو موجود الآن

| الملف | الغرض |
|---|---|
| `schemas/atlas.schema.json` | نموذج البيانات: المصدر، المقطع، الادعاء، الكيان، الحدث، ملف المقابلة، السنّة، نص المستوى |
| `prompts/constitution.md` | دستور الوكيل، يُرسل بصيغة موجّه النظام |
| `prompts/claim_extraction_v1.md` | موجّه استخراج الادعاءات |
| `prompts/sentence_check_v1.md` | موجّه فحص الجملة المنشورة مقابل مصادرها |
| `pipeline/normalize.mjs` | توحيد النص العربي (التشكيل، الهمزات، التطويل، الأرقام) ومطابقة الاقتباس الحرفي |
| `pipeline/validate.mjs` | التحقق من أي كيان مقابل المخطط |
| `fixtures/sample_claims.json` | بيانات اختبار مصطنعة، ليست نصاً من مصدر ولا تُنشر |

```
node --test pipeline/normalize.test.mjs

```

## ما ينتظر قرارات بشرية أو مفتاح API

- **لا يوجد مفتاح API** في البيئة، فلم يُشغَّل أي استخراج بالنموذج بعد.
- اختيار الكتب الثمانية للموجة الأولى ومراجعة قائمتها: قرار تحريري.
- تشكيل نواة التحرير ومؤلف الفحص الحرفي: أدوار بشرية.
- الاستشارة القانونية لطبقات الترخيص قبل إدخال أي نص محمي.

## قواعد لا تُكسر

- كل اقتباس يمر بـ `checkQuote` قبل أن يصير ادعاءً.
- الادعاء الذي يفشل المطابقة يُرفض، والذي يظهر مرتين يُحال للمراجعة.
- الجملة المنشورة لا تُنشر قبل فحص `sentence_check_v1`.
- المعرّفات الثابتة لا تتغير أبداً. التصحيح يضيف إصداراً جديداً.

## مسار الاستخراج عبر الدفعات (Batch API)

| الأمر | ماذا يفعل | يتصل بالشبكة؟ |
|---|---|---|
| `node pipeline/extract_batch.mjs plan <passages.jsonl> <outDir>` | يبني الطلبات ويقدّر الكلفة ويرفض المقاطع فوق 90 ألف رمز | لا |
| `node pipeline/extract_batch.mjs submit <outDir> --budget-usd N` | يرسل الدفعة بعد التحقق من السقف والمفتاح | نعم، بعد الموافقة |
| `node pipeline/extract_batch.mjs collect <passages.jsonl> <outDir>` | ينتظر النتائج ويطابق كل اقتباس | نعم |

بوابات الإرسال: لا إرسال بدون `--budget-usd`، ولا إن تجاوزت الكلفة المقدّرة السقف، ولا بدون `ANTHROPIC_API_KEY`.

الاختبارات: `node --test pipeline/normalize.test.mjs pipeline/extract_batch.test.mjs` (20 اختباراً).

الطراز: `claude-haiku-5-5` كما سمّاه المالك في الخطة. التسعيرة في الكود مأخوذة من الجدول الحالي وتُراجع قبل كل دفعة.

## الطبقات الحقوقية

| الطبقة | المعنى | يدخل الاستخراج؟ |
|---|---|---|
| A | في الملك العام | نعم |
| B | مرخّص، أو محمي بإذن موثّق | نعم، بعد توثيق الإذن |
| C | مرجع للإحالة فقط | لا أبداً |

قصة الحضارة لديورانت في الطبقة C: يُستخدم فهرسه وترتيبه للحقب، وتُسجَّل إحالات إليه، لكن لا يُستخرج منه نص ولا اقتباس. المصادر الأولية التي يستند إليها (الطبري، هيرودوت، ابن كثير…) تُستخرج من طبقتها الحقيقية.

`plan` يرفض أي مقطع طبقته C أو غير معلنة.

## الواجهة (Node.js + MapLibre GL)

- `web/index.html` و`web/app.js`: خريطة تعرض مواقع الحقب الأربع الأولى (`web/data/places_era1..4.geojson`) بأزرار تبديل.
- `web/vendor/`: ملفات MapLibre GL 4.7.1، منسوخة من `node_modules` لتعمل بلا CDN.
- تشغيل محلي: `cd web && python3 -m http.server 8000` ثم افتح `http://localhost:8000`.
- الإحداثيات في الملف **تقريبية ولم تُراجع** بعد مع Pleiades، وتحمل `coord_status: approximate`.

## جلب المصادر المفتوحة

- `sources/manifest.json`: قائمة المصادر مع الترخيص والطبقة.
- `node scripts/fetch_sources.mjs`: يجلب الملفات، ويسجّل SHA-256 وتاريخ الجلب لكل ملف.
- يرفض المصادر من الطبقة C أو بلا ترخيص معلن، ويتخطى المصادر التي لا رابط ملف مؤكداً لها.
- الروابط في `manifest.json` فارغة حالياً، لأن الجلسة لا تصل إلى مواقع Pleiades وHYDE وCDLI وSeshat. تُملأ بعد تحقق بشري من صفحات التنزيل.

## بناء ملف المواقع

- `npm run build:places`: يبني `web/data/places_era1.geojson` من `data/raw/pleiades-places-latest.csv.gz` وفق `scripts/config/places_era1.json`.
- يفشل كاملاً إن لم يطابق أي موقع عنوانه المتوقع، ولا يكتب ملفاً ناقصاً.
- كل ملف مبني يحمل `raw_sha256` للملف المصدر، فيمكن إثبات أي مخرج إلى مدخله.
- `npm test`: الاختبارات القائمة (21 اختباراً).

## الحقب على الخريطة

- كل حقبة لها إعداد في `scripts/config/places_eraN.json`، وملف مبني في `web/data/places_eraN.geojson`.
- الحقب المبنية الآن: 1 إلى 4. كل إعداد يُبنى بـ `npm run build:places`، وعدد المواقع في كل ملف يُطبع عند البناء.
- الحقبتان الأولى والثانية: أغلب المواقع بإحداثيات Pleiades، وما بقي تقديري وموسوم بلون أفتح (في الحقبة الثانية مجدو وأوغاريت).
- الحقبتان الثالثة والرابعة: كل المواقع بإحداثيات Pleiades، ولا مواقع تقديرية.
- مدن العصر الإسلامي المؤسسة (بغداد، الكوفة، البصرة، الفسطاط، القيروان) غير موجودة في Pleiades، فلا تظهر بعد.
- الواجهة تعرض أزرار تبديل بين الحقب، وعدد ادعاءات كل حقبة في `web/data/claims_index.json`.

## ربط الادعاءات بالخريطة

- `npm run build:claim-points` يبني نقاط الأماكن من Pleiades (`scripts/config/claim_places.json`، مع مطابقة العنوان قبل البناء)، ثم يربط كل ادعاء موثّق (مطابق للنص) بالمكان الذي يذكره في `mentions.places`.
- زر "عرض الادعاءات على الخريطة" في الواجهة يعرض النقاط، والنقر عليها يعرض ادعاءات المكان مع الاقتباس والمصدر والتحفظ.
- أماكن الادعاءات غير المرتبطة بعد (أوفير، ترشيش، يهوذا، الصين، نانجينغ، بكين) تُسجَّل في `web/data/claim_points.geojson` ضمن `_meta.unlinked_mentions`، ولا تُعرض حتى يكون لها إحداثيات موثوقة.

## لوحة التحولات (مطابقة جغرافية)

- `npm run build:transitions` (`scripts/build_transitions.py`) يقارن كل خريطتين من الإحدى عشرة (عشر سنوات من Historical Basemaps، والدول اليوم من Natural Earth): 55 ملفاً في `web/data/transitions/{أ}__{ب}.json`.
- يقرأ الملفات الخام لا المبسّطة، ويُصلح الهندسة غير الصالحة (`make_valid`)، ويوحّد المضلعات المتحدة الاسم كياناً واحداً. المضلعات بلا اسم لا تُعدّ كيانات.
- المساحات جيوديسية (كرة بنصف القطر الأصيل لـ WGS84). لكل كيانين يُحسب نصيب كل منهما من أرض الآخر، ثم يُصنَّف:
  - **مصير كيان السنة الأولى:**
    - بقي اسمه
    - خلفه اسم آخر (أكثر من النصف من الجهتين)
    - انقسم (كيانان فأكثر أخذ كل منهما 10%)
    - دخل في كيان أوسع (ربع أرضه فأكثر)
    - تقلّص
    - توزّع
    - زال (أقل من ربع أرضه تحت كيانات مسمّاة)
  - **منشأ كيان السنة الثانية** بالمرآة: خلافة، اندماج، اقتطاع، نشأة من كيان وتوسّع، تجميع، أرض بلا اسم.
- العتبات في `_meta.thresholds` لكل ملف. هذه **علاقات مكانية** بين خريطتين، لا أحكام بالسببية أو الوراثة القانونية، ولا ترى ما جرى بين السنتين.
- `node scripts/check_transitions.mjs` (ضمن `check:all`) يتحقق من:
  - اكتمال الأزواج
  - مطابقة العدّ
  - تناظر الخلافة وبقاء الاسم من الجهتين
  - صحة الأنصبة
- اعتماديات بايثون في `requirements.txt` (`pip install -r requirements.txt`).

## السنن (طبقة التركيب)

السنن **فرضيات تُختبر بالشواهد**، لا قوانين حتمية. كل سُنّة في `sunan/sunan.json` لها:

- **نص ابن خلدون** من المقدمة العربية (ويكي مصدر، `data/raw/wikisource_muqaddima`)، ويُطابَق كل اقتباس بالنص آلياً.
- **شواهد مؤيدة** و**شواهد مقيِّدة**، كل منها يحيل إلى ادعاء موثّق (مطابق لنص مصدره).
- **تقدير صريح لقوة الشواهد**: متعددة، أو قليلة، أو بلا شواهد مؤيدة بعد.
- **قراءات حديثة** بإحالة عامة لم تُقتبس (Turchin، وPopper، وAcemoglu وRobinson).

السنن السبع الحالية: العصبية والملك، وأعمار الدول، والترف والهرم، واقتداء المغلوب بالغالب، والأمن على الأموال وعمران الأسواق، والتجارة ومراكزها، والصنائع وانتقال المعرفة.

## الأوامر

- `npm run check:all`: كل المدققات (مطابقة الاقتباسات، والمقابلات اليونانية، والسنن). يفشل عند أي اقتباس أو شاهد غير موثّق.
- `npm run build:all`: يعيد بناء ملفات الواجهة (المواقع، والادعاءات، وأماكنها، والسنن، وورقة المراجعة).
- `npm run build:basemap`: يبني خريطة الأساس من Natural Earth.

## الواجهة

افتح `web/index.html` عبر خادم محلي (مثلاً `python3 -m http.server` داخل `web`). فيها وضعان: **مبسّط** (الادعاء والمصدر) و**باحث** (مع الاقتباس الأصلي والتحفظ والقراءات الحديثة).

## الاختبار الكمي للسنن (Seshat)

`analysis/` يختبر ثلاث سنن ببيانات Seshat (CC BY-NC-SA): أعمار الدول، والتجارة ومراكزها، والصنائع والعمران. النتائج في `analysis/seshat_results.json`، والتقرير في `analysis/README.md`، وتظهر في بطاقة كل سُنّة بالواجهة مع حكم مشتق من فترة الثقة (يؤيد، أو لا يؤيد، أو غير حاسم). إعادة التشغيل: `npm run analyze:seshat`.
